# QuickMath App
A simple React application that is a Mental Math Trainer. Soon, there will be timers, more metrics saved, and firebase authentication and databases hooked up so that this application can be better. 

### 7/6/2025
The application now has a built in countdown. This will later be expanded upon to be customizable into different presets the user chooses. Firebase authentication has been set up and works smoothly. The default page is the log in page, where you can be redirected to sign in. After that, you are routed to the Home page. Next step is to add in more game functionality. That is, different difficulties, time restraints, and maybe an endless mode. Then, the metrics from each session will be sent to the database. Another next step is to set up a navigation bar where you can go to a stats page and see your progress.
